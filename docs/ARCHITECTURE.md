# 当前架构边界（2026-10-20）

1. **输入**：用户的结构化修改请求及受限原始 RV32 机器码。解析器提取寄存器、控制流和有限绝对内存依赖。超出已支持指令、地址及程序大小的输入会拒绝。
2. **C64 红区**：固定共享循环 GRU，64 轮推断；原权重是研究对照的稳定基线。一次只输出单字节 `PATCH` 或 `STOP`，修改后重新编码和计算。
3. **RGB 蓝区／绿区**：绿区压缩静态关系信息，蓝区给出快速草案或 STOP，红区校验或回退。v2 的风险判断未通过无损晋升；优化后的执行后端仅显式启用。
4. **Hybrid v1**：StateLink 接受 64 维状态及绿区摘要，在检查点做内部 THINK 或 EMIT。监督训练动作头和桥后，以完整轨迹回报训练模式策略。强化学习只训练模式决策，不对连续隐藏状态虚构词元概率。
5. **模板层**：不可变输入底稿、精确请求结果缓存、保持静态解析边的模板缓存、可逆字节差量。模板相近不等于请求或神经隐藏状态相同。

当前接口输出 `PATCH <offset> <hex-byte>` 或 `STOP`，不是聊天文本生成、忠实思维解释或通用软件修复。任何程序修改都会令先前的图状态可能失效，不能简单复用上次隐藏状态。

运行模式默认仍使用未被候选替换的固定 C64。所有实验候选都必须在冻结起点、无标签预测输入、独立执行检查、完整公开回归和新保留测试后，再决定是否晋升。
