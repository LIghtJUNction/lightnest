# LightNest v7：主动区分行为比盲目增加样例有效，但结构假设不能冒充证明

日期：2026-10-29（UTC）。本轮为 RGB 命名空间下的可选研究模块，不接管 RGB 主线的字节生成器、不替换权重或正式模型指针。源码与原始结果分开保存。

## 结论

在同一组全新留出行为上，从32个初始样例出发，再获得32个答案，主动询问策略完整恢复155/256次（60.55%），随机询问为0/256。所有方法使用相同的最少边界解码器；改变的是询问哪个输入。分母是64种完整行为×4组初始样例，不是256个独立软件项目。

这不是无外部帮助的生成成绩。每次询问都获得参考执行器的真实答案，新增32个答案完整计入预算。32个样例、不询问时三组均为0/256。没有重新训练大型神经网络；只从训练数据拟合了一个结构先验参数。

去掉拟合先验，保留同一结构类并采用类内均匀先验，主动询问达到157/256，略高于155/256。故证据支持“选择有区分力的问题”，不支持“学习到的先验带来额外优势”。这条非神经方法是可复现对照和规划模块，不是宣称通用智能或RSI突破。

## 1. 从数学上重新定位困难

### 1.1 没有结构约束时，样例不足以确定程序

考虑字节输入、布尔输出：完整行为是256位向量 y。看过m个不同输入后，若允许任意布尔函数，仍有 2^(256-m) 个行为符合所有样例。任何学习器面对两个在已知位置相同、未知位置不同的目标，都会收到同样输入，因而不可能保证同时答对。

这不是说现实函数必须随机，也不是对本实验真实函数族的成功率上界；它说明额外信息或可辩护的结构先验不可省略。不能把所有失败都归于模型不够大。

### 1.2 把可能解释压缩成动态规划，而不是只留下一个猜测

令 T(y)=sum_i [y_i != y_(i-1 mod N)]，即环上的输出变化次数。环边界适合v6使用的模256平移/反射任务，但它是显式任务先验，不是所有程序的性质。

本轮声明 H_K={y:T(y)<=K}，主实验 N=256、K=12。推断保留全部与已知答案一致的行为，而不是先按神经网络分数删到一个候选。类内先验为：

    P_beta(y) = exp(-beta*T(y)) / Z_beta,  y in H_K

一个环的变化次数必为偶数；变化次数为k的行为数量是 2*C(N,k)。理由是选择k条翻转边，再选择第一个输出位。k为奇数不能闭环。因此：

    Z_beta = sum_(k even, k<=K) 2*C(N,k)*exp(-beta*k)
    d log Z_beta / d beta = -E_beta[T]

使用v6的2,176个训练行为拟合一维最大似然参数，匹配训练平均变化次数2.8860294118，得到beta=4.468180454334647。训练数据之外的答案不参与拟合。无观察时主结构类包含约2^67.79个行为；代码不逐一枚举。

动态规划状态为“当前位置、当前输出位、已使用变化次数”，分别固定首位0和1，最后加入闭环边。前向/后向计数给出每个未知位置的两种答案分别支持多少行为。计算采用float64正项运算，组合计数和后验数值是浮点近似，不冒充任意精度整数；可行性由正路径是否存在判断，不用置信度阈值代替支持集。

单次后验的当前实现时间复杂度O(N*K^2)、存储O(N*K)。前后向递推本身O(N*K)，边界计数的合并贡献K^2。已经用252组小域穷举配置核对概率、可行支持、行为数量及最少边界解码，未发现不一致；这不是对所有浮点平台的形式化证明。

### 1.3 主动问什么

设观察集为S。对于确定性答案：

    I(Y; answer_at_x | S) = H(answer_at_x | S)

原因是给定完整行为Y后，该位置的答案不再有随机性，条件熵为零。因此选择后验答案熵最大的未知输入，就是贪心最大化这一次问答的信息量。答案得到后，排除所有与它冲突的行为，继续推断。

可选接口支持 entropy/cost 的比值，但这是成本敏感启发式，不声称全局最优；主实验所有询问成本均取1。主动学习/版本空间/反例驱动合成均有先行研究，本轮不是首创这些方法。具体新工作是本项目中的环形有限行为后验、数据拟合、失败诊断、原生循环组合以及可复现对照。

不保证每次减半：可用输入未必能均匀分开所有候选。本轮没有宣称达到log2候选数的最优问答下界。

### 1.4 为什么可以扩展到长数组

一旦两个字节谓词p与q在全部256个字节上相同，则它们的count、first、prefix三个固定循环在任意有效数组上相同：

* count：循环不变量 c_i=sum_(j<i) p(a_j)。由i到i+1只加p(a_i)，逐点相等保持不变量。
* first：到达位置i意味着之前所有谓词值为0；两谓词在i的结果相同，因此在相同位置停止，或都返回n。
* prefix：到达位置i意味着此前全为1；同理得到相同的首个0位置，或都返回n。

这是从局部规则到固定循环语义的数学归纳论证。它要求正确的边界检查、有效可读内存和符合约定的编码后端。本轮没有用Lean证明机器码后端，也没有把有限原生测试称为机器码全输入证明。

## 2. 数据与实验边界

真实逻辑和原生标签继承v6的musl v1.2.5字符判断实验。重新用GCC编译v6参考C，运行产生1,703,936字节标签，与归档逐字节相同。参考C是对musl表达式的适配，不是完整编译musl或使用生产软件日志。

训练沿用2,176个去重行为。新测试从4个旧留出函数族的未用平移/反射变体中各取16个，共64个；完整256位真值表与v6训练、开发、A测试、B测试均不相同。仍是同项目、相关源函数的变体，不是跨项目留出。测试行为的变化次数为4、6、8，均在主类K=12内。

每个行为4个初始掩码，分别给32或128个答案。三种策略分别为训练先验熵、类内均匀先验熵、随机。最多新增32个答案，在0、8、16、32处报告结果。学习器只收到已知位置及答案；完整参考表仅供按请求返回答案和只读计分，不作为错误定位器给出反例。

各策略的候选均为最少边界的一致行为，固定确定性平局规则。评估全部256个输入严格相等，而不是按字节准确率计成功。初始样例和随机序列按任务/掩码固定。全部结果保留，无选种子、检查点晋级。协议在本机测量前保存，并非外部预注册。

## 3. 主结果

每格为256次评价。相同目标的4个掩码属于重复测量。

| 初始样例 | 新答案 | 随机询问 | 主动：拟合先验 | 主动：类内均匀先验 |
|---:|---:|---:|---:|---:|
| 32 | 0 | 0 | 0 | 0 |
| 32 | 8 | 0 | 2 | 1 |
| 32 | 16 | 0 | 16 | 16 |
| 32 | 32 | 0 | 155 | 157 |
| 128 | 0 | 8 | 8 | 8 |
| 128 | 8 | 11 | 143 | 147 |
| 128 | 16 | 12 | 225 | 226 |
| 128 | 32 | 20 | 233 | 232 |

主比较为32+32，提升60.55个百分点。把每种完整行为的4个掩码先平均，对64个行为作10,000次成对重采样，描述性95%百分位区间为[51.56,69.53]个百分点。它仅描述这64个相关变体的重采样，不证明跨源函数族/跨项目收益；未作普遍显著性宣称。

若保持同一询问序列，换用不训练的环形最近样例解码，32+32主动拟合先验为153/256，随机为1/256；128+32分别为233/256和15/256。收益主要来自选择样例，而非该解码器压倒简单方法。

主方法32+32平均CPU时间0.1710秒/次，随机0.0301秒，约5.68倍。主实验对齐答案预算，不对齐推断算力。该时间包含保存点的后验诊断与解码，不是纯查询策略微基准，且排除既有v6标签生成成本。整体研究测量墙钟约165.6秒。不能称作等计算量胜出。

冻结的三个v6局部网络额外用于同一新数据的初始样例诊断：32样例原始输出0/768；128样例15/768，强制保持已知样例后20/768。没有重训这些网络，也没有给它们相同的主动询问流程，所以这不是端到端神经网络对抗实验。

## 4. 最重要的负面结果：范围内唯一可能是错的

主类K=12下，所有6144条保存预测的“类内唯一”均为false。即使候选实际正确，已有答案仍不足以排除该结构类中的其他解释。模块没有把高概率或实测猜对冒充证明。

另按协议测试更窄的K=4，64个行为各用32个初始样例及最多32次主动询问：

* 12个任务产生显式矛盾，接口报 InconsistentEvidence，不抛弃不合意的观察。
* 36个任务在错误的结构类中收敛到唯一解释，但该解释实际上错误。
* 剩余16个目标属于K=4类，未出现上述错误。

这说明“找到唯一程序”的论证还需要“真实程序确实属于候选类”。`conditional_unique`特意保留条件限定，不等于`verified`；没有自动部署或模型晋级逻辑。大模型置信度也不能自动补上这个前提。

## 5. 真正运行带内存和循环的候选

新增固定可信后端，把预测的256位行为表和三种已写好的循环组合成x86-64函数：

* count：统计符合谓词的字节数。
* first：返回第一个符合谓词的位置，没有则返回n。
* prefix：返回连续符合谓词的前缀长度。

调用约定为RDI=输入地址、RSI=长度、RAX=结果。每次输入加载之前比较索引和长度；只读输入，不进行文件或网络访问。函数体分别为297、305、305字节，包括256字节查表数据。行为由推断产生，循环、指令编码、ELF头和运行框架由人工后端提供。不是RGB神经生成器直接输出完整ELF的新成绩。

原生诊断固定取64个目标的mask0、32+32主动拟合先验输出，不按成功与否筛选。生成192个循环函数实例，每个279个输入用例，共53,568个原生输出。每组包含空数组、全部256种单字节、随机长度、边界匹配、131,072字节长输入，以及与系统libc strspn/strcspn核对的非NUL字符串。

全部192个函数的机器执行均与其编码的预测谓词一致，后端差异为0。但只有126/192个完整符合真实目标，等价于42/64个正确谓词×3种固定循环。剩余66个仍保存为失败，不能用“机器码执行正常”掩盖行为错误。192不是192种独立学习出的算法。

独立子进程执行器在运行候选前完成I/O、设置内存/CPU/输出限制，降权并限制系统调用。输入只读，末端紧邻不可访问页。测试覆盖空输入越界、输入写入及不允许的系统调用。它是研究隔离措施，不是安全认证。

演示ELF为4,560字节，内嵌4,096字节真实测试输入，输出计数992；真实运行验证。文件变大主要是输入数据，不是4KB新程序逻辑。该演示依赖32个初始答案加32个外部答案，不算单次无反馈成功。
