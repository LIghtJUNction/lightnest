# 下一轮：保质量的自适应计算（准备方案）

**目标**：在不增加误改、不丢失基线成功样例的条件下减少推断成本；现阶段优先验证，而不是放宽门槛或晋升 Hybrid v1。

## 固定实验设计

1. **先冻结**：指定 C64 / RGB v1 两个现有种子 104729、130363 的权重指纹、环境、预算、训练流及全套旧回归；另生成按构造组隔离、此前未评价的新保留集。现有 Hybrid v1 新测试不可再次用作新预留。
2. **做对照**：固定相同演员，分别对比固定 64 轮、监督切换、Hybrid RL、加入“若继续思考可修复则禁止早退”的反事实轨迹监督、仅增同额监督更新对照。训练次数、有效样本及运行时间分别记录。
3. **限制错误早退**：让模式策略学习“继续运行直到可靠”，测量首次 STOP 错误、错误修改后 STOP、混合长依赖失败，并以追加完成度监督替代简单的每步省计算奖励；任何风险阈值只在公开校准集设定。
4. **独立效率线**：先对比相同动作输出下的编译/批量循环后端；其次分开测精确缓存命中、静态图复用和端到端延迟。缓存键绑定完整输入、模型、运行版本和租户；另测 0%、50%、90% 重复率，不把受控高重复率当线上事实。
5. **严格发布门槛**：新保留需编辑任务的完整成功率和“成对成功”至少不低于父模型；新保留与全部公开回归均不得新增正确程序误改，不得丢失父模型任意旧成功记录；仅在两起点都符合、且相同输出语义下实测节省延迟时才将开关默认打开。

## 本轮产物要求

只将通过审查的最新 Python 源码、可复现命令、冻结方法、对照报告与失败分析加入仓库。训练数据、`.pt`、`.jsonl`、大结果及候选输出仍存云盘。报告明确区分训练调用、独立任务数、墙钟延迟与货币成本。未经证实的改进一律标注为待验证假设。

**当前状态：实验方案已准备；本次只复核已有档案与源码测试，没有训练新的模型或产生新的准确率成绩。**
