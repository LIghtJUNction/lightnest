# Research v2：四条路径实测，结构规则胜出，神经候选不晋升

日期：2026-10-20（UTC+8），测量日志使用 UTC。原始起点 `0b3d1ffb98be169563fb4aef69c995122cb80726`；本轮运行源码 `dfb04887931a820bba7e333abdcc30b5550d3264`。默认 C64、旧权重和原始档案保持不变。

## 结论

已实际实现动作稳定后提前输出、16 轮一次预测全部修改、64 轮一次预测全部修改、反向依赖规则四条候选路径，完成四个新判断头的训练。加入原 C64、两个固定阈值对照和始终 STOP，共评价八种策略。

**本轮受限 ADD/SUB 结构变换任务的最优可选工具是反向依赖规则。** 新测试 384/384 编辑完整成功、384 个正确程序零误改、192/192 个返回来源配对全部成功；2,372 条公开回归全部通过，零旧成功丢失。它没有运行神经网络，不是模型学会了这些能力。

**没有神经候选通过晋升。** 按两个起点均无新增误改和旧成功丢失的条件，保留 C64 作为神经基线。规则只作为显式研究工具，不改默认入口，不宣称能安全修改任意真实软件。

## 方法与任务

原 C64 在每次编辑后重新运行 64 轮。早退出方案保留原权重，在 16、24、32、48、64 轮检查动作；连续三个检查点的离散动作一致且达到概率阈值才提前输出，第 64 轮强制输出。概率和动作一致不是正确性证明。

两个一次性修改方案使用冻结 C64 的 16／64 轮特征，训练 133→64→1 的指令级判断头。特征包括 64 维状态、64 维请求表示、4 个字节和1个位置。一次计算完整修改列表，再输出 STOP。这是新的决策方式，不是无损缓存旧策略的隐藏状态。

反向依赖方案从返回值沿已有解析器的依赖关系反向遍历，修改相关 ADD/SUB 指令。**规则和新判断头均额外使用 12 条固定请求文本、ADD/SUB 候选筛选及固定功能位翻转。** 它们不学习任意请求和任意替换字节；不能把与原 C64 的系统差异全归因于网络改进。16／64 轮判断头之间则对齐训练流、初始头和更新预算。

新测试有 192 个构造组、768 条记录：384 条需编辑、384 条不可编辑；八类各 96 条。384 条普通长度，336 条为 13—20 长链范围，48 条仍是简单控制题；机器码 48—488 字节。与 112,332 条历史发布索引和可访问的 Hybrid／RGB 数据做字节与中和结构指纹检查，冲突为零。每题 16 组执行输入，两套解释器构建检查共 49,152 次调用。没有用模型分数构建或筛选新测试。

新题仍来自既有生成器的新种子和更长程序，不是真实缺陷或全新算法族。结构指纹隔离不等于语义去重。每种预测只接收 `command` 和 `binary`；答案、分组和执行结果不进入预测。完整成功要求最多 8 次编辑后明确 STOP、最终字节等于目标、执行检查通过；正确程序提出任何编辑均算误改。

## 实际训练与选择

两个固定起点 104729、130363，各训练两种深度，共四份判断头，每份新增 8,641 参数。只用此前 TRAIN 的 3,584 条状态、2,614 个构造组。每份 768 次 AdamW 更新，批量 32，学习率 0.001，权重衰减 0.01，梯度上限 1；正例损失权重 2，先在每个状态内平均，再对采样状态平均。

合计 **3,072 次更新、98,304 次状态展示**，展示含重复。两个深度的同起点采样索引完全相同；每份接触不同状态分别为 3,581、3,581、3,582、3,582。特征计算合计 100.003 CPU 秒，判断头更新合计 4.738 CPU 秒，两段合计 104.741 CPU 秒；不含加载、校准、回归、测试、复算与计时。不能仅用判断头更新时间描述全实验成本。环境为 Python 3.13.5、PyTorch 2.10.0+cpu、NumPy 2.3.5，Torch 单 CPU 线程，无 GPU、外部模型接口或外部子 agent。

352 条公开校准选出提前退出阈值 0.9、0.9；16 轮保守阈值 2、2；64 轮保守阈值 2、3。看到公开校准中保守头近乎不修改后，在任何新测试之前登记固定阈值 0 与始终 STOP 对照，没有重训。`driver-amendment.json` 时间为 2026-10-19 19:41:23 UTC；全部方案选择在 19:47:05 UTC 固定，记录新测试查询数为 0。随后才测试所有终点，未按新测试调参或换种子。

## 反例与采用边界

五个单列语义反例为 `x XOR x`、`x-x`、乘零、与零、恒真分支导致不可达。规则仍提出编辑，虽然这些位置不影响最终结果；每例用 8 组输入、两套解释器核对修改前后相等，另有相应代数恒等式或恒真分支理由。它们不计入原结构标签的评分，也没有改写旧答案。

**结构相关不等于实际语义影响。** 本轮满分说明当前结构任务能被确定性方法解决，不说明神经理解突破。新工具仍不支持计算地址、复杂别名、调用或任意语言请求。预检查已在新入口统一拒绝计算地址，避免继承解析器两条路径行为不一致；原默认路径没改。

采用决定：受限结构变换使用反向依赖作为显式工具；神经基线保留 C64；通用语义修复没有胜出者，不自动开启研究路径。下轮优先增加代数/可达性证据和“结构相近但真实影响不同”的成组测试，而不是继续仅凭本类模板提分。
